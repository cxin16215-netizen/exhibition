10.23消除工坊原型已实现

从泡泡龙设想，收敛到三消建造

建立交换、资源、建筑与敌人推进的最小可玩循环。

展开详细过程 +收起 −
发现的问题
想做消除与肉鸽结合，但仅给普通消除加升级，差异还不够清楚。
设计决策
先做最小可玩：交换、连消、产资源、建筑响应与敌人推进。作为独立Unity模块，避免被主项目流程绑定。
工作流程
讨论消除与肉鸽方向 → 收敛最小循环 → 制作独立Unity原型 → 根据初次可玩反馈继续扩展。
结果与证据
确定“消除决定资源，资源驱动战线”的原型；早期每消一格给经验，再三选一成长。
边界／待验证
最初确认的是可玩与值得继续，不是已经完成数值平衡或内容量验收。
依据

10月23日原型设计对话；MatchForge README早期说明

10.23—10.24消除工坊已实现

从颜色匹配，到局外配盘

同色混消、特质产出，关前携带决定本局资源池。

展开详细过程 +收起 −
发现的问题
自动连锁很爽，但如果每局固定三种棋子，局外没有构筑空间；复杂特质也不能把最基本的匹配弄难读。
设计决策
匹配看颜色，收益看特质；加入四连、T/L与五连的延迟奖励。关前选择携带元素，并限制颜色数量与职业必要资源。
工作流程
先补形状奖励 → 将匹配颜色与收益特质分离 → 加入局外携带 → 扩展元素并检查职业必要资源。
结果与证据
盘面从固定方块池变为携带选择。后续扩到六色十二元素：同色特质可混消，但掉落权重会随携带组合变化。
边界／待验证
颜色数改变连锁频率，也改变绿色木材供应，后来成为职业平衡的重要变量，尚未证明所有搭配等强。
依据

元素携带、特殊形设计对话；《new-elements》及盘面实现资料

10.23—10.25消除工坊多轮修订

从“有特效”，改到“看得懂发生了什么”

调整特效覆盖、状态表现、伤害数字与选中反馈。

展开详细过程 +收起 −
发现的问题
命中特效太小难以察觉；后来统一放大，又挡住棋子细节。冰冻与击退曾只像一行文字。
设计决策
把反馈分到消除、资源、弹道、命中和状态；按消除规模分级，约束覆盖面积。伤害数字按主要贡献元素着色，选中目标分加载与射程两层提示。
工作流程
根据可见性反馈反复修改 → 调整粒子尺度和覆盖 → 补状态、数字与选中层次 → 否决遮挡信息的统一大特效。
结果与证据
冻住、推开和命中逐步有可见表现；卡牌与前景增加衬底和轮廓，防止细节背景吞掉重要信息。
边界／待验证
聊天里多次否决“更大就是更爽”的美术方案。美术修改不等于已经做完可读性用户测试。
依据

消除特效、命中与读条修改对话；《world-sound-and-light》

九个世界不只换一张背景

用主题生物、环境音画和首领机制区分九个世界。

展开详细过程 +收起 −
发现的问题
同一种铠甲敌人换色，无法支撑九个世界；只有远景建筑也缺少临场感。
设计决策

结果与证据

边界／待验证
世界数量说明内容组织规模，不直接代表每关节奏、强度与机制可见性均已验收。

10.24—10.26消除工坊已实现

元素应先有日常价值，再做首领答案

补足元素日常用途，加入跨手储备与多种反制路线。

展开详细过程 +收起 −
发现的问题
若元素只在某一首领面前有效，就只是钥匙；若首领吞掉玩家唯一输出，又会变成无解配装。
设计决策
要求每种元素平时也有用途，并保留多条对抗路线。锚石、镜片、时砂改为跨手积累，而非再添三种即时伤害。
工作流程
逐个检查日常用途 → 讨论首领反制是否有替代路线 → 接入跨手储备与复制边界。
结果与证据
十二元素覆盖供能、控制、资源与储备；镜片有复制边界，时砂承担危险时刻的缓冲。
边界／待验证
机制可用与数值值得携带是两个问题，后者还要在颜色数、职业与首领组合中验证。
依据

元素通用价值与首领反制对话；《new-elements》

10.25消除工坊已接入战役

从单怪倒计时，到可利用的生态战线

加入意图预告、分批增援和可利用的敌人关系。

展开详细过程 +收起 −
发现的问题
单一敌人的威胁容易只剩DPS检查；多怪一起贴脸又不给玩家形成计划的时间。
设计决策
保留十格行动轨道，提前显示目标和意图；分批、分距离到达。加入互斗、捕食、护卫等生态关系，让敌人也成为可利用的对象。
工作流程
从战术切片验证多怪与意图 → 调整增援距离和批次 → 接入战役 → 扩展生态关系与EX。
结果与证据
血量、防御、攻击和集火形成战术层，九章EX围绕生态组合展开。目标死亡时不偷偷把锁定攻击改向基地。
边界／待验证
连锁存在随机性，因此不把精确压到同血量这类细操作作为唯一解。生态组合仍需正式试玩验证稳定性。
依据

《tactical-slice》《ecological-encounters-v1》《implementation-professions-ex》；战线设计对话

10.25消除工坊已接入远征

把成长强度与打法选择拆开

木材负责数值成长，卡牌负责打法，减少重复选择。

展开详细过程 +收起 −
发现的问题
经验卡和木材升级同时加攻击，选择重复；共用升级次数又使买一条线阻止另一条成长。炮台存能过多会淹没敌人机制。
设计决策
数值成长由木材承担，炮台火力、装填、供能各计两级；卡牌负责改变打法。基础只存两发，多一发作为卡牌分支入口。
工作流程
比较经验卡和木材的重复职责 → 分离数值与打法 → 取消共用升级次数 → 接入波间整备、弹仓分支与提前迎战。
结果与证据
远征取消按消除刷经验的成长入口，改为固定波次木材、偶数波整备与选卡。场上清空时可提前迎战，减少空等。
边界／待验证
职业扩展后，十八张是炮术师卡池；机关师与护幕师使用各自卡池，不能把炮台规则套给所有职业。
依据

《workshop-economy》《inspiration-cards》；经验、弹仓、提前迎战讨论

10.25—10.26消除工坊已接入

用职业改变资源如何变成胜利

将同一盘面产出接成三套职业资源循环。

展开详细过程 +收起 −
发现的问题
只换伤害倍率和外观，不足以让三种职业有不同决策。
设计决策
保留同一套交换规则，分别用自动炮火、路径机关和护幕体系承接产出；职业建筑、资源用途与卡池分开。
工作流程
先讨论各职业三建筑 → 定义资源用途与卡池 → 接入三职业和EX → 将首版体验问题带入后续重做。
结果与证据
首版三职业与九章EX接入，为后续机关师与护幕师重做提供了可比较的基线。
边界／待验证
首版的地桩／绞盘／回收、彩色盾与主动放电后来已替换；不能继续拿首版说明介绍当前职业。

10.26 · 第04轮消除工坊实现待试玩
